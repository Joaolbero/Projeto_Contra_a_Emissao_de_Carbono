## 📄 Descrição / Description

| 🇧🇷 **Descrição (PT-BR)** | 🇺🇸 **Description (EN)** |
| --- | --- |
| Site estático em HTML, CSS e JavaScript focado em conscientização sobre emissão de carbono e sustentabilidade. Inclui uma landing page principal, página “Sobre” e página de ação com fluxo simples via WhatsApp. | Static website built with HTML, CSS and JavaScript, focused on raising awareness about carbon emissions and sustainability. It includes a main landing page, an “About” page and an action page with a simple WhatsApp call-to-action flow. |
