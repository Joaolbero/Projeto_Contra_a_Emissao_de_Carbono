## 📄 Descrição / Description

🇧🇷 PT-BR  
Site estático sobre conscientização ambiental, redução de emissões de carbono e ações sustentáveis. Possui página inicial, página “Sobre”, página de ação (“Adote”) e integração com WhatsApp.

🇺🇸 EN  
Static website focused on environmental awareness, carbon emission reduction, and sustainable actions. Includes landing page, About page, action page (“Adopt”) and WhatsApp CTA.
